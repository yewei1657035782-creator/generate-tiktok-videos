# Creative Direction Library

Use these as starting worlds, not fixed presets. Present 3–5 suitable directions as text first and make them materially different while keeping the same Product Identity Lock.

## Direction construction

Every option must define:

1. Setting and architectural language.
2. Season, time of day, light direction, and weather.
3. Palette and supporting materials.
4. People, wardrobe, behavior, and prop styling.
5. Lens character, depth, camera energy, and sound intent.
6. Best-use case and fidelity risk.

Avoid empty phrases such as `high-end luxury`. Name the visible evidence: honed limestone, controlled sunset rim light, restrained tailoring, long-lens compression, sparse table styling, or architectural shadow lines.

## Selection and continuity

- Do not generate any reference image before the user selects from the text options.
- Generate reference images only for the selected options. Keep them comparable through the same product identity, aspect ratio, and hero framing.
- Select one world for a 15-second sequence. Do not jump between unrelated locations.
- Build richness within that world through a hero zone, social-use zone, material-detail zone, structure zone, and environmental transition.
- A subtle time progression is allowed when light direction and grading remain motivated.
- Record the selected world in the product project history so future campaigns can deliberately repeat or avoid it.
