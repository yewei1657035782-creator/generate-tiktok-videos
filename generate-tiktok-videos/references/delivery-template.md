## 12. Final QA

- [ ] Product silhouette, proportions, color, material, components, pattern, and logo remain stable.
- [ ] No hidden structure, dimension, function, accessory, claim, certification, or result was invented.
- [ ] Every shot has an approved frame or is clearly marked pending/blocked.
- [ ] Each video prompt uses one approved frame and describes one editable single shot.
- [ ] Generated visuals contain no captions, prices, promotions, or random typography.
- [ ] Shot durations equal the target runtime.
- [ ] Filenames map directly to the edit timeline.
- [ ] Revision status and unresolved risks are explicit.
- [ ] Product ID, source archive, and project history are recorded.
- [ ] Content type was selected before creative planning.
- [ ] Scene-style options were presented as text before any style reference image was generated.
- [ ] Reference images exist only for the user-selected scene styles.
- [ ] All frames follow the selected Visual World Lock.
- [ ] Product-review claims, tests, comparisons, limitations, and verdicts are supported by supplied or visible evidence.
- [ ] Every required individual clip has a verified path, duration, aspect ratio, and playback status.
- [ ] Every delivered clip came from an official watermark-free export/download route.
- [ ] Full-playback inspection confirmed no visible 可灵/Kling watermark, platform logo, or platform overlay.
- [ ] No platform watermark was cropped, blurred, covered, inpainted, overlaid, or otherwise concealed.
- [ ] No full-video assembly was performed.
