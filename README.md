# generate-tiktok-videos

可复用的 Codex 产品视频生成技能：先选择产品展示或产品评测，再选择场景风格；生成 5–7 个独立分镜和视频片段，支持批量提交，并强制使用官方无水印导出。

## 安装

把下面的链接发给 Codex，并要求安装此技能：

https://github.com/yewei1657035782-creator/generate-tiktok-videos/tree/main/generate-tiktok-videos

也可以在命令行执行：

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo yewei1657035782-creator/generate-tiktok-videos \
  --path generate-tiktok-videos
```

安装完成后，在下一轮对话中调用 `$generate-tiktok-videos`。
